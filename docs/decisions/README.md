# Decisions

One register for consequential product (PDR) and architecture (ADR) choices.
Identifiers and historical acceptance are preserved; the prefix describes the
concern, not a separate workflow. [Template](_template.md).

Use Proposed, Accepted, Superseded, Rejected or Deprecated. An accepted decision
may describe future work; [plans](../plans/README.md) own implementation and
acceptance, while [references](../README.md) describe current contracts. Read the
relevant record when investigating or changing a choice, not the entire history.
