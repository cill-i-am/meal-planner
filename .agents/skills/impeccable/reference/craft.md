# Craft (deprecated alias)

`craft` is a deprecated alias for an ordinary request to make new visual work. It adds no setup, interview, checkpoint, tool, or quality behavior. Apply SKILL.md's normal routing and follow [new-work.md](new-work.md) for the requested design. Use [init.md](init.md) only when the user asks to record product context.

Do not tell users they need to invoke `craft`. Natural requests such as “build this feature,” “make a landing page,” or “redesign this screen” use the same flow.
