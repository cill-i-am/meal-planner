# Shape a surface

Produce the smallest useful design brief from the request, relevant product
context, supplied visual references, and source. Resolve available facts before asking
questions. Ask only about material unresolved purpose, scope or design choices;
there is no mandatory interview round for an already precise or agreed task.

Capture the job/audience, observable outcome, content/states, chosen interaction
and layout, constraints, exclusions, and actual open decisions. Deliver the brief
in the requested destination. Preserve existing tool metadata only when the task
needs it; do not create a separate design or handoff record by default.

For a new surface or substantial redesign, use [new visual work](new-work.md) to
develop the composition using the requested tool or supplied references. Reuse agreement already obtained. A shape-only
request delivers the brief; a request that also assigns implementation continues
through that work once its real design decision is resolved.
