# Craft checks

Use these techniques when the assigned surface needs them. Live Paper is visual
authority; the approved design and real product requirements determine the result.
A clean detector is supporting evidence, not design acceptance. Reuse relevant
hook findings and one rendered inspection for related checks.

## Check the implemented result

- **Contrast and semantics:** verify the applicable accessibility requirements.
  As a baseline, body/placeholder text needs 4.5:1 contrast and large text 3:1.
  Check labels, control names, focus visibility and keyboard order.
- **Spacing and hierarchy:** inspect real computed values, grouping, reading
  order and the relationship between content and its primary action.
- **Typography:** test real copy, zoom, wrapping, font loading and content ranges
  at affected breakpoints. Use the established type scale and source fonts.
- **Motion:** preserve purposeful motion from the approved design, respect reduced
  motion and check performance. Add motion only when it serves the assignment.
- **States:** inspect applicable hover, disabled, loading, error, empty and success
  states using working controls and truthful content.
- **Assets and material:** verify source quality, aspect ratio, transparency where
  required, and visible fidelity. Keep text and controls semantic; use SVG for
  geometry and appropriate images for photographic or textured material.
- **Copy and coverage:** use product terminology; controls name actions and errors
  name recovery. Every assigned requirement must be present and findable.

## Diagnose visual drift

Inspect repetitive card scaffolds, competing decoration, unnecessary labels,
inconsistent shadows/radii, category-default colors, typography used as costume,
and placeholder icons. These are prompts to examine fit, not universal bans.
Compare each questionable choice with the approved Paper composition, neighboring
patterns and user task. Preserve a deliberate approved device; fix an accidental
implementation defect at its narrowest cause. A craft preference never authorizes
replacing the agreed design.

Report actual evidence gaps, access or recovery defects and factual uncertainty.
Keep domain consent and real validation intact while refining presentation.
