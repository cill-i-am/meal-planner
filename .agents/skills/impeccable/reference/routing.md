# Choose a design technique

For an explicit command or surface, use the corresponding reference in SKILL.md
and remain within the request. Do not turn command-selection advice into execution
or run every detector simply to display a menu.

For a bare invocation, inspect available project/design context and suggest the
single most relevant next technique with its reason. No tool is required merely
to make that suggestion. When the user also requests execution, carry out the
assigned work rather than stopping after the suggestion.

Typical routes: new composition → new-work; planning brief → shape; hierarchy/UX
assessment → critique; accessibility/runtime defects → audit/harden; refinement →
polish; specific layout/type/motion problems → that topic's reference. Preserve the
agreed design, actual product truth and task completion boundary throughout.
