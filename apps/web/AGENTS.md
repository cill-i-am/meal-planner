# Web interface design

Use [PRODUCT.md](PRODUCT.md) for the interface's product context. The [Impeccable config](.impeccable/config.json) owns the build-path default.

For new surfaces and substantial visual redesigns, develop the selected composition in Paper and refine it with the user. Start application UI coding only once the user and agent agree that the Paper design is ready. Retain a reference to the agreed Paper design with the scoped design work so the implementation can be checked against it.
