# shadcn components

Button and Input use the shadcn/ui base-nova registry source with Base UI primitives. Field uses the vertical form subset of that registry. Local imports, formatting, and the Meal Planner theme are adapted for this application. Existing notebook classes remain the styling hooks for screens outside authentication.

Sources: [Button](https://ui.shadcn.com/r/styles/base-nova/button.json), [Input](https://ui.shadcn.com/r/styles/base-nova/input.json), and [Field](https://ui.shadcn.com/r/styles/base-nova/field.json). The reviewed registry snapshot is in `.impeccable/reference/shadcn-base-nova`.
